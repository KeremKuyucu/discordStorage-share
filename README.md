# DiscordStorage-Share

DiscordStorage-Share, DiscordStorage uygulamasına entegre edilmiş bir paylaşım modülüdür.  
Bu modül sayesinde kullanıcılar **Discord üzerinde dosya paylaşımı ve indirme** işlemlerini mobil uygulama üzerinden gerçekleştirebilir.

---

## ⚡ Özellikler

- 🔗 Dosya paylaşımı ve indirme **Discord mesaj ID** üzerinden  
- 🗃️ Dosya **Discord üzerinde saklanır**, ek veritabanı veya geçici kayıt gerekmez  
- ✅ Kullanıcı sadece **mesaj ID** paylaşarak dosya indirebilir

---

## 📋 Gereksinimler

- Discord bot token → `BOT_TOKEN` (env)  
- Discord channel ID → `DISCORD_CHANNEL_ID` (env)

> Bu iki env değişkeni yeterlidir.

---

## 🚀 Kullanım (Mobil Uygulama)

1. **Dosya Yükleme:**  
   - Uygulamada dosya seçilir ve yüklenir  
   - Bot, dosyanın mesaj ID’sini döner  
   - Kullanıcı bu ID’yi paylaşabilir

2. **Dosya İndirme:**  
   - Kullanıcı paylaşılan mesaj ID’yi girer  
   - Dosya Discord’dan indirilir
